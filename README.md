# DSA Problem Solving in C++

This repository contains my solutions to various Data Structures and Algorithms (DSA) problems implemented in C++.

## 📚 Topics Covered

### Basic Programs

- **Fibonacci Series** - Generate Fibonacci sequence
- **Prime Numbers** - Check if a number is prime
- **Reverse Number** - Reverse digits of a number
- **Square Root** - Calculate square root of a number
- **Sum Calculator** - Calculate sum of numbers
- **Largest Number** - Find the largest among numbers

### Pattern Problems

The `Patterns/` directory contains various pattern printing programs:

- Pattern 1 - Basic pattern designs
- Pattern 2 - Number patterns
- Pattern 3 - Star patterns
- Pattern 4 - Complex patterns
- Pattern 5 - Advanced pattern designs
- Pattern 6 - Additional pattern designs
- Pattern 7 - Palindromic number pyramid

#### Character Patterns

The `Patterns/Characters/` directory contains character-based pattern programs:

- Problem 1 - Character pattern printing
- Problem 2 - Character type identification
- Count Type - Count different types of characters in input
- Checking Value - Value validation program

## 🛠️ Technologies Used

- **Language**: C++
- **Compiler**: GCC/G++ or any C++ compiler

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/RITESH-CHAUHAN2005/DSA.git
cd DSA
```

2. Compile any C++ file:

```bash
g++ filename.cpp -o output
```

3. Run the executable:

```bash
./output
```
